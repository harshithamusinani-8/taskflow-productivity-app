# TaskFlow — Focus. Finish. Flow.

TaskFlow is a modern and responsive **Task Management + Quick Capture Chat application** built using HTML5, CSS3, and Vanilla JavaScript.

It provides a clean productivity workspace where users can create, manage, search, filter, and complete tasks. Users can also capture ideas through the Quick Capture chat panel and instantly convert them into tasks.

---

## 🚀 Features

### 📋 Task Management

- Create new tasks
- Mark tasks as completed
- Reopen completed tasks
- Delete tasks
- View all tasks
- View active tasks
- View completed tasks
- Task creation date display

### 🔎 Search & Filtering

- Search tasks instantly
- Filter by:
  - All
  - Active
  - Completed
- Real-time task count updates

### 💬 Quick Capture Chat

- Capture ideas through the chat panel
- Add chat messages directly to the task list
- Delete captured messages
- Simple and intuitive chat interface

### 📊 Productivity Dashboard

- Total task count
- Active task count
- Completed task count
- Today's completion percentage
- Dynamic progress bar

### 💾 LocalStorage

TaskFlow uses browser LocalStorage to save:

- Tasks
- Chat messages
- Theme preference

Your data remains available even after refreshing the browser.

### 🌙 Dark Mode

- Light mode
- Dark mode
- Theme preference is saved automatically

### 📱 Responsive Design

TaskFlow works across:

- Desktop
- Laptop
- Tablet
- Mobile devices

The sidebar automatically adapts to smaller screens.

### ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + N` / `Cmd + N` | Focus new task input |
| `/` | Focus search |
| `Enter` | Add task / Send chat |
| `Esc` | Close mobile sidebar |
